# 轨道故障台

《人工智能基础与应用》互动作品。先读三条模拟卫星遥测曲线，选择故障，再查看实际设定与近邻模型的判断。点击「增加干扰」，查看同一案例是否改判。

- **基础演练**：每局一种故障，适合快速上手。
- **进阶诊断**：包含设备正常、单项故障和两项故障组合，共七类。可拖动回放定位检查三条曲线在同一分钟的读数。提交后揭晓模拟故障发生时间、近邻票数和三项特征变化量，可切换四档干扰复测同一局。
- 两种模式分别记录本次打开网页以来的正确局数。切换模式会开始新局，刷新后重新计分。

## 访问和运行

- 在线演示 [GitHub Pages](https://eric-donk.github.io/orbital-fault-lab/)
- 本地安装 Node.js 后，在此目录运行 `node serve.mjs`，浏览器打开 `http://127.0.0.1:4173`。
- 模型检查 `node --test model.test.mjs`。
- 重跑基础实验 `node experiment.mjs`；重跑进阶实验 `node experiment.mjs --advanced`，输出各组识别结果与混淆矩阵。

网页无需安装 JavaScript 依赖或配置 API 密钥。Chrome、Edge、Firefox 等现代浏览器可直接访问部署页面。

## 制作说明

- `index.html`、`site.css`、`app.mjs` 分别负责页面结构、视觉和交互。
- `model.mjs` 用固定种子生成温控、供电、通信三类模拟故障训练样本。每条曲线记录 18 个时间点。取前 4 点和后 5 点的均值差作为三维特征，用训练集尺度标准化后计算欧氏距离，由最近的 5 条训练样本投票。
- 模拟器用未参与训练的 180 个案例测试。原始条件保留生成过程中的随机小波动，干扰条件再叠加额外的随机波动、漂移和偶发尖峰。两种条件使用同一批底层案例，数值均限制在 0–100。
- 第一局是固定演示例，特地选来展示干扰后的改判。模型实验使用另外的固定测试集。遥测、故障与示意卫星图用于课堂展示。
- 进阶模式另用 840 个案例训练、280 个留出案例测试（每类 40 个）。在同一批测试案例上逐档增加干扰，组合类必须完全匹配才计为正确。结果仅反映所设定的模拟环境。
